# Практическая работа 06. Сравнительный анализ средств антивирусной защиты

Дисциплина: «Основы информационной безопасности». Продолжительность: два академических часа.

## Профессиональная задача

Вы инженер защиты рабочих станций. Руководитель просит выбрать средство по результатам небольшого пилота. Производители условные; цифры являются учебными наблюдениями, а не сравнением реальных продуктов.

## Входные данные и рабочая среда

[Скачать исходный файл](data/06_%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81.csv). Все названия, люди, события и оценки в наборе синтетические. Работайте с копией, исходник сохраните. Достаточно текстового редактора и программы просмотра CSV; установка средств защиты и платные сервисы не требуются. Интернет нужен только для дополнительной сверки официальных источников; офлайн-результат явно отделяйте от подтверждённой актуальности.

**Профиль учреждения:** 10 рабочих станций учебной части, один ответственный аналитик. Дистанционная изоляция узла обязательна. На первичный разбор антивирусных событий выделено 60 минут в день; остаток рабочего времени занят другими задачами. Совместимость средств с электронным журналом пока не проверена и считается неизвестной, а не подтверждённой. Решение по таблице — выбор кандидата для следующего пилота, не разрешение на немедленное развёртывание.

**Смысл полей:** «изоляция» показывает, поддерживает ли средство по условиям кейса дистанционное ограничение сетевого взаимодействия узла при сохранении канала управления; это не результат испытания функции в инфраструктуре учреждения. «Агентов актуально» — число из 10 агентов, которые на момент снятия учебного отчёта работали на согласованной для пилота версии программы и базы обнаружения; доля не показывает состояние в другие дни. Числа обнаружений и тревог получены на фиксированном тестовом наборе, а не на суточном потоке файлов. Время сканирования измерено для этого набора в одинаковых условиях.

## Порядок работы

1. Вычислите для каждого средства полноту обнаружения: обнаружено /20; частоту ложных тревог: ложные тревоги /80; актуальность агентов: актуальных /10. Представьте расчёты с исходными знаменателями.

2. Оцените, почему максимальное обнаружение Гаммы не доказывает её преимущество. Учтите ложные тревоги, охват обновлений и отсутствие изоляции. Скорость сканирования сама по себе не измеряет защиту.

3. Выберите кандидата для следующего пилота по профилю учреждения. Сначала примените обязательное ограничение по изоляции, затем оцените обнаружение, ложные тревоги, актуальность и неизвестную совместимость. Обоснуйте компромисс; запрещено объявлять победителя по одной колонке. Объясните, каких данных о ежедневном потоке событий не хватает, чтобы проверить бюджет 60 минут.

4. Предложите следующий этап испытаний: состав выборки, повторяемость условий, проверка совместимости, реакция на события и восстановление. Отдельно перечислите выводы, которые нельзя сделать из 20 вредоносных файлов.

## Сдаваемый результат

Расчёты.csv и заключение пилота.md с кандидатом, обязательными ограничениями, неизвестными условиями и планом их проверки. В отчёте у каждой рекомендации должны быть основание из входных данных, ответственный и способ проверки. Не заполняйте неизвестные поля догадками.

 Всего 100 баллов. Для защиты за 3–5 минут объясните одно решение, одну альтернативу и одно ограничение данных. Исправленная после замечания работа должна содержать краткую историю изменений.

Частичные баллы — по [общей рубрике](КАК_РАБОТАТЬ.md#оценивание).

## Усложнение

Рассчитайте трудозатраты на разбор ложных тревог именно тестового набора при учебном допущении 10 минут на событие. Выразите результат в минутах. Затем перечислите данные, необходимые для оценки ежедневной нагрузки и её сопоставления с бюджетом 60 минут; не выдавайте результат тестового набора за суточную нагрузку.
