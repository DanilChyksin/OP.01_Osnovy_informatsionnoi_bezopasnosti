# Практическая работа 05. Модели доступа и разграничение полномочий

Дисциплина: «Основы информационной безопасности». Продолжительность: два академических часа.

## Профессиональная задача

Вы администратор управления доступом. Получена матрица, в которой рабочие функции смешаны с накопившимися привилегиями. Нужно исправить права так, чтобы учреждение продолжило работу.

## Входные данные и рабочая среда

[Скачать исходный файл](data/05_%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF.csv). Все названия, люди, события и оценки в наборе синтетические. Работайте с копией, исходник сохраните. Достаточно текстового редактора и программы просмотра CSV; установка средств защиты и платные сервисы не требуются. Интернет нужен только для дополнительной сверки официальных источников; офлайн-результат явно отделяйте от подтверждённой актуальности.

## Порядок работы

1. Найдите минимум пять проблем. Для каждой укажите нарушенный принцип, возможное последствие и конкретную правку. Чтение всех групп студентом и чтение собственной записи — разные права.

2. Постройте исправленную матрицу с объектными границами. Разделите создание и утверждение платежа, ограничьте роль службы копирования, отзовите доступ уволенного сотрудника.

3. Составьте шесть тестов: три разрешённые и три запрещённые операции. У каждого должны быть субъект, объект, действие, ожидаемое решение и подтверждение в журнале.

4. Опишите порядок изменения: согласование владельцем, проверка зависимостей, применение, отзыв сеансов и секретов где требуется, повторные тесты и фиксация результата. Объясните, почему снятие роли без отзыва действующего сеанса может быть недостаточным.

## Сдаваемый результат

Матрица_после.csv, тесты_доступа.csv и план изменения.md. В отчёте у каждой рекомендации должны быть основание из входных данных, ответственный и способ проверки. Не заполняйте неизвестные поля догадками.

## Проверка и защита

Выявление проблем 25; минимально необходимые права 35; тесты 25; безопасное внедрение 15. Всего 100 баллов. Для защиты за 3–5 минут объясните одно решение, одну альтернативу и одно ограничение данных. Исправленная после замечания работа должна содержать краткую историю изменений.

**Частичные баллы по каждому указанному критерию:** 0 — соответствующий сдаваемый артефакт/расчёт отсутствует либо вывод не проверяется по исходным данным; половина максимума — основная часть артефакта есть, но обработана не вся требуемая выборка, пропущена проверка или допущена исправимая ошибка; полный максимум — артефакт охватывает все предусмотренные строки/сценарии, расчёты воспроизводимы, выводы имеют основания, неизвестность отмечена явно. Для критерия с нечётным максимумом допустимы половинные баллы, например 12,5 из 25. По каждому снижению преподаватель указывает конкретную строку отчёта, тест или отсутствующий результат. Текст без требуемого анализа данных не считается полным выполнением.
