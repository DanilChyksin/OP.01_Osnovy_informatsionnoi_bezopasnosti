# Практическая работа 01. Работа с официальным сайтом ФСТЭК России

Дисциплина: «Основы информационной безопасности». Продолжительность: два академических часа.

## Профессиональная задача

Младший аналитик готовит руководителю проверяемую справку вместо подборки случайных ссылок. Организация выбирает меры защиты, но отдел закупок предлагает довериться скриншоту продавца. Ваша задача — отделить официальный источник, вспомогательный материал и неподтверждённое утверждение.

## Входные данные и рабочая среда

[Скачать исходный файл](data/01_%D0%B8%D1%81%D1%82%D0%BE%D1%87%D0%BD%D0%B8%D0%BA%D0%B8.csv). Все названия, люди, события и оценки в наборе синтетические. Работайте с копией, исходник сохраните. Достаточно текстового редактора и программы просмотра CSV; установка средств защиты и платные сервисы не требуются. Интернет нужен только для дополнительной сверки официальных источников; офлайн-результат явно отделяйте от подтверждённой актуальности.

## Порядок работы

1. Для каждой строки S1–S5 определите, какой вопрос источник способен подтвердить и чего из него нельзя заключить. Не считайте официальный домен доказательством применимости любого найденного документа.

2. Составьте маршрут проверки: найти документ или запись, установить автора и дату, проверить редакцию и область действия, сохранить подтверждение. Для сертификата отдельно зафиксируйте продукт, версию и условия.

3. Если есть Интернет, откройте официальный сайт ФСТЭК и БДУ. Найдите одну карточку документа и одну карточку угрозы либо уязвимости. Запишите URL, название, дату доступа и назначение карточки: какое конкретное утверждение она помогает проверить и какие поля служат подтверждением. Если связи нет, оформите план поиска по входному каталогу: для S1–S5 укажите целевое утверждение, ожидаемый раздел/тип карточки, необходимые поля и следующий шаг. Статус фактической проверки, редакции и актуальности ставьте «не проверено». Не сочиняйте содержание, номера, URL конкретных карточек и даты их посещения.

4. Напишите ответ закупщику на 100–150 слов: какие утверждения пока нельзя использовать для решения и какие подтверждения нужно получить. Не выдавайте неизвестное состояние за отрицательный результат проверки.

## Сдаваемый результат

Справка источники.md: таблица S1–S5, маршрут проверки и краткое решение. Онлайн-режим дополнительно содержит две найденные карточки с подтверждающими полями. Полноценный офлайн-результат вместо карточек содержит две заполненные карточки-планы: целевое утверждение, официальный маршрут поиска, необходимые подтверждения и статус «не проверено». Поля неизвестного содержания остаются явно неизвестными; фиктивные результаты поиска не принимаются. В отчёте у каждой рекомендации должны быть основание из входных данных, ответственный и способ проверки. Не заполняйте неизвестные поля догадками.

## Проверка и защита

Релевантность источников 30; воспроизводимость маршрута 30; разделение фактов и неизвестного 25; ясность справки 15. Всего 100 баллов. Для защиты за 3–5 минут объясните одно решение, одну альтернативу и одно ограничение данных. Исправленная после замечания работа должна содержать краткую историю изменений.

**Частичные баллы по каждому указанному критерию:** 0 — соответствующий сдаваемый артефакт/расчёт отсутствует либо вывод не проверяется по исходным данным; половина максимума — основная часть артефакта есть, но обработана не вся требуемая выборка, пропущена проверка или допущена исправимая ошибка; полный максимум — артефакт охватывает все предусмотренные строки/сценарии, расчёты воспроизводимы, выводы имеют основания, неизвестность отмечена явно. Для критерия с нечётным максимумом допустимы половинные баллы, например 12,5 из 25. По каждому снижению преподаватель указывает конкретную строку отчёта, тест или отсутствующий результат. Текст без требуемого анализа данных не считается полным выполнением.

## Усложнение

Если преподаватель предоставил конкретную сохранённую копию с датой получения, сравните её с текущей карточкой и зафиксируйте различия, не смешивая дату копии с датой редакции. Если такой копии нет, выберите два утверждения из запроса закупщика и спроектируйте независимую проверку каждого: источник, необходимые поля, возможное противоречие и действие при его обнаружении. Сравнение с несуществующей копией не требуется.
