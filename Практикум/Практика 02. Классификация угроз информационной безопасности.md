# Практическая работа 02. Классификация угроз информационной безопасности

Дисциплина: «Основы информационной безопасности». Продолжительность: два академических часа.

## Профессиональная задача

Вы аналитик учебного учреждения. До выбора средств защиты нужно показать руководству, что именно может быть нарушено и какие изменения реально снижают риск. Перечень активов специально содержит технические и организационные слабости.

## Входные данные и рабочая среда

Интернет нужен только для дополнительной сверки официальных источников; офлайн-результат явно отделяйте от подтверждённой актуальности.

## Порядок работы

1. Для A1–A4 постройте по одному сценарию: источник → действие или событие → слабость → нарушаемое свойство → последствие для деятельности. Назовите источник отдельно от актива.

2. Классифицируйте сценарий по намеренности, происхождению источника и свойству информации. Одна угроза может нарушать несколько свойств; не сводите классификацию к единственной колонке.

3. Для каждого сценария предложите одну предупредительную и одну восстановительную меру, владельца исполнения и проверку эффективности. Формулировка установить защиту без проверяемого результата не принимается.

4. Выберите два первоочередных сценария и обоснуйте выбор последствиями и достижимостью. Укажите неизвестные сведения, которые могут изменить приоритет. При доступе к БДУ сопоставьте один сценарий с действительной карточкой; не придумывайте код УБИ.

## Сдаваемый результат

Реестр угроз.csv с четырьмя сценариями и записка приоритеты.md. В отчёте у каждой рекомендации должны быть основание из входных данных, ответственный и способ проверки. Не заполняйте неизвестные поля догадками.

## Проверка и защита

| Критерий | Баллы |
|---|---:|
| Причинная модель | 35 |
| классификация | 20 |
| адресность мер | 25 |
| обоснование приоритета | 20 |

 Всего 100 баллов. Для защиты за 3–5 минут объясните одно решение, одну альтернативу и одно ограничение данных. Исправленная после замечания работа должна содержать краткую историю изменений.

Частичные баллы — по [общей рубрике](КАК_РАБОТАТЬ.md#оценивание).
