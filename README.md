## Теория и практическая работа

Лекции сокращены до существенных понятий, необходимых моделей и ограничений. Каждая лекция содержит не более 6000 слов и схему; изображения хранятся в `images` и открываются непосредственно в Markdown на GitHub.

[Практикум: 10 профессиональных кейсов](Практикум/README.md). В каждой работе есть синтетические исходные данные, задача анализа, сдаваемый результат, критерии оценки и усложнение. Ключ преподавателя размещён отдельно внутри практикума; для контрольного занятия его не выдают заранее.
